# Entrega 9 - Cintia Casagrande

## Proyecto

Proyecto correspondiente a la **Entrega 9** del curso de Excel.

El objetivo es desarrollar un modelo de datos y un dashboard a partir de un dataset de ventas de una empresa del sector industrial/autopartista.

## Herramientas utilizadas

* Microsoft Excel
* Power Query
* Power Pivot
* Tablas dinámicas
* Segmentadores
* Dashboard

## Contenido del archivo

El archivo `Entrega9_Casagrande_Cintia.xlsx` contiene:

* Dataset principal de ventas.
* Tablas de dimensiones y datos maestros.
* Transformación y limpieza de datos mediante Power Query.
* Modelo de datos mediante Power Pivot.
* Relaciones entre las tablas.
* Indicadores clave de desempeño (KPIs).
* Dashboard para el análisis de las ventas.
* Segmentadores para facilitar la interacción con la información.

## Modelo de datos

El modelo relaciona la información de ventas con las tablas correspondientes a:

* Clientes
* Productos
* Calendario

Las relaciones permiten analizar las ventas desde diferentes dimensiones y generar los indicadores utilizados en el dashboard.

## Indicadores

El dashboard presenta indicadores relacionados con:

* Ventas Brutas
* Bonificaciones
* Ventas Netas
